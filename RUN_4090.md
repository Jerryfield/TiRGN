# TiRGN on RTX 4090

The original `requirement.txt` uses `torch==1.6.0` and `dgl-cu102==0.5.2`.
That CUDA 10.2 stack is not suitable for RTX 4090. Use the CUDA 11.8
environment below instead.

## 1. Create Environment

```bash
cd /newSSD/MrLiu/hwb_project/TiRGN
conda env create -f environment_4090.yml
conda activate tirgn4090
```

If an old broken environment already exists, create this as a new environment
instead of repairing the base environment.

## 2. Install Dependencies

Install PyTorch first. RTX 4090 needs a newer CUDA stack than the original
`cu102` dependencies. CUDA 11.8 is a conservative choice for driver 535.

```bash
python -m pip install --index-url https://download.pytorch.org/whl/cu118 torch==2.0.1+cu118 torchvision==0.15.2+cu118
```

Then install DGL with the matching CUDA 11.8 wheel:

```bash
python -m pip install dgl==1.1.3+cu118 -f https://data.dgl.ai/wheels/cu118/repo.html
```

Finally install the remaining Python packages:

```bash
python -m pip install numpy==1.24.4 scipy==1.10.1 pandas==1.5.3 tqdm rdflib
```

## 3. Check CUDA

```bash
python -c "import torch; print(torch.__version__, torch.version.cuda, torch.cuda.is_available()); print(torch.cuda.get_device_name(0))"
python -c "import dgl; print(dgl.__version__)"
```

Expected result:

```text
2.0.1+cu118 11.8 True
NVIDIA GeForce RTX 4090
1.1.3
```

If `torch.cuda.is_available()` is `False`, check whether a different PyTorch
build was installed accidentally. Do not use `torch==1.6.0` or `dgl-cu102`
on RTX 4090.

## 4. Generate History Files

Run this once for each dataset you want to train or test.

```bash
cd /newSSD/MrLiu/hwb_project/TiRGN/src
python get_history.py --dataset ICEWS14
```

This creates files under:

```text
../data/ICEWS14/history/
```

## 5. Run ICEWS14

```bash
cd /newSSD/MrLiu/hwb_project/TiRGN/src
python main.py -d ICEWS14 --history-rate 0.3 --train-history-len 9 --test-history-len 9 --dilate-len 1 --lr 0.001 --n-layers 2 --evaluate-every 1 --n-hidden 200 --self-loop --decoder timeconvtranse --encoder convgcn --layer-norm --weight 0.5 --entity-prediction --relation-prediction --add-static-graph --angle 14 --discount 1 --task-weight 0.7 --gpu 0 --save checkpoint
```

Add `--test` to evaluate an existing checkpoint with matching parameters.
