`s1_probs.npz`。

## S1：错误预测（时间切分 70/30，train 18708 / test 7736，禁止随机切分）

标签：top-1 ≠ gold（基线错误率 65.3%）。LightGBM 二分类。

| 特征 | AUROC（整体） | AUPRC | 桶 0 AUROC | 桶 1-9 AUROC | 桶 10+ AUROC |
|---|---|---|---|---|---|
| TiRGN 间隔（5 维） | 0.7568 | 0.8355 | 0.7791 | 0.7793 | 0.7507 |
| 全特征（间隔+E1-E4） | **0.7781** | 0.8510 | 0.8119 | 0.8019 | 0.7710 |
| 全特征+LLM 置信（1500 子集） | 0.6745 | 0.7028 | - | - | - |
| └ 同子集去掉 LLM | 0.6828 | 0.7020 | - | - | - |

- 证据特征增量：+0.0214 AUROC（0.7568→0.7781）；LLM 置信增量：**-0.0084（负）**。
- **决策规则判定：中间分支**——AUROC 0.778 ≥ 0.70 达标，但证据特征提升 +0.021 < 0.03 →
  方法降级为"**校准的 TiRGN**"：错误可预测性主要来自模型自身的分数间隔，证据/LLM 特征贡献边际。

## S2：风险-覆盖曲线（时间切分 holdout 上的弃权价值）

| 置信信号 | AURC | MRR@cov1.0 | MRR@cov0.8（弃权 20%） | MRR@cov0.5 |
|---|---|---|---|---|
| TiRGN 间隔（GBDT） | 0.2626 | 0.4517 | 0.5058（+0.054） | 0.6131 |
| 全特征（GBDT） | 0.2661 | 0.4517 | **0.5129（+0.061）** | 0.6199 |
| LLM 置信（1500 子集） | 0.2634 | 0.5195 | 0.5301（+0.011） | 0.5333 |

弃权 20% 查询后保留集 MRR 提升 5-6 个点——**选择性预测是整条研究线中唯一显著成立的价值形态**，
但信号主体仍是 TiRGN 自身间隔（全特征仅再 +0.007）。

## S3：协议伪影实验（同一批 LLM 输出，三种口径三个结论）

| 协议 | 结果 | 表观结论 |
|---|---|---|
| (a) 全量 1500 标准协议（融合增益） | -0.0006 | 负：无效果 |
| (b) 200 条抽样 × 20 次（AnRe 式） | 均值 -0.0010，std 0.0033，**45%（9/20）的抽样为正**，范围 [-0.0097, +0.0068] | 结论随抽样翻转：小样本协议近半数概率"发现"正效果 |
| (c) 候选 AUC（ExE 式，9 负例） | 0.5435 | "正"：AUC>0.5 看似有效 |

这是分析向论文的关键图：**LLM 验证在 (c) 口径下"有效"、(b) 口径下"掷硬币"、(a) 口径下无效**。
协议差异（小样本 + AUC 指标对 top-1 重排不敏感）足以凭空制造表观增益，
提示文献中同类正面结论需要在其协议敏感度下重新审视。

## 决策与后续

1. 选择性预测方法章节**降级成立**：故事是"校准的 TiRGN + 弃权机制"（S2 弃权 20% → +6 点 MRR），
   证据/LLM 特征不提供核心增量；
2. S3 协议伪影实验补全了分析向论文的最后一块：
   统计触顶（D2）→ 类比无力（D3）→ LLM 负收益（P2）→ 恢复失败（P3）→ **协议敏感度（S3）**；
3. 可选讨论：把"错误可预测（AUROC 0.78）+ 弃权收益"写成短方法节，与分析主线
   （证据路线为什么都不工作）形成"能救的不是排名而是信任"的统一叙事。
