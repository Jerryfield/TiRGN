# 服务器任务：选择性预测可行性测试 + 协议伪影实验（全部基于现有缓存，预算 1 天）

## 背景
LLM 证据验证路线已按决策规则终止（P2 -0.0023 / P3 1.4%，见 docs/task5_pilot/pilot_summary.md）。
完整证据链：统计触顶（D2）→ 类比无力（D3）→ LLM 验证负收益（P2）→ 恢复失败（P3）。
存活的核心科学问题从"证据能否改进排名"收缩为"**能否预测 TiRGN 何时会错**"（选择性预测/弃权）。
本任务决定方法章节是否成立，同时为分析向论文补最后一个实验。

## 任务 S1：错误预测（纯 CPU，缓存特征）
1. 标签：seed1 测试缓存中每条查询 top-1 是否为 gold（错=1）；
2. 特征：E1-E4 全部 + TiRGN 分数间隔（top1-top2、top1-top10 均值等）+ P2 缓存的 LLM 置信度（p2_llm_scores.jsonl，仅 1500 条有）；
3. 模型：LightGBM 二分类，按时间切分 train/valid（禁止随机切分，防泄漏）；
4. 报告：整体与分桶（0 / 1-9 / 10+）AUROC、AUPRC，以及只用 TiRGN 间隔特征的消融（判断证据特征是否有增量）。

## 任务 S2：风险-覆盖曲线（方法的价值形态）
1. 用 S1 的错误概率作为置信信号：弃权和保留 MRR 的关系曲线（coverage 1.0→0.5 步进 0.05）；
2. 对比三条曲线：TiRGN 间隔单特征 / GBDT 全特征 / LLM 置信度（有缓存的子集上）；
3. 报告 AURC，以及"弃权 20% 查询后保留集 MRR"这个直观数字。

## 任务 S3：协议伪影实验（分析向论文的关键图）
1. 从 P2 的 1500 条已评分查询中按 AnRe 方式随机抽 200 条 × 20 次，计算 LLM 判断在小样本下的"表观效果"分布；
2. 同批数据分别按 (a) 全量 1500 条标准协议、(b) 200 条抽样、(c) 99 负例 AUC（ExE 风格）三种口径报告 LLM 验证的"效果"；
3. 目标：用同一批模型输出证明结论随协议翻转，量化协议差异造成的表观增益。

## 决策规则
- S1 全特征 AUROC ≥ 0.70 且相比 TiRGN 间隔单特征 AUROC 提升 ≥ 0.03 → 选择性预测方法章节成立；
- S1 达标但证据特征无增量（提升 < 0.03）→ 方法降级为"校准的 TiRGN"，故事变薄，需讨论；
- S1 AUROC < 0.65 → 方法路线清空，全力写分析向论文，并与导师讨论换题（agentic TKGQA 方向）。
- 产出 docs/task6_selective/selective_summary.md + results/task6_selective/。
