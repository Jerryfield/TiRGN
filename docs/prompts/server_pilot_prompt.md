# 服务器任务：LLM 语义证据试点（go/no-go，单次小规模，预算上限 2 天）

## 背景
Phase-2 + 诊断包已证明：ICEWS14 上统计形态证据（自身历史/关系路径/类比计数）触顶（天花板 = 重复计数 0.4415），
但 oracle 空间 0.36 闲置、0 历史桶 MRR 仅 0.28、20% 查询 gold 在 Top-50 外。
文献核查（2026-09）确认"冻结 LLM 语义验证 + 标准协议"尚无人占据，但 RECIPE-TKG（生成式+微调）
与 ExE-LLM（统计证据语言化+DTGB 协议）从两侧挤压。本试点决定 LLM 路线生死。

## 核心假设
LLM 的价值只在**计数统计之外的语义信号**：读懂路径/历史的文字内容并做组合判断。
若冻结 LLM 在小样本上无法超过统计天花板，则整条 LLM 证据路线终止。

## 任务 P1：样本与证据语言化（CPU）
1. 从 seed1 测试集缓存抽取 2000 条查询分层样本：0 历史桶 500 / 1-9 桶 500 / 10+ 桶 500 / gold∉Top-50 的查询 500；
2. 对每条查询的 Top-10 候选语言化证据：直接历史 (s,r,o,t')、1-2 跳关系路径（实体关系用名称不用 id）、时间间隔；
   每条候选证据控制在 150 token 内，格式固定。

## 任务 P2：冻结 LLM 验证（单卡 4090，Qwen3-8B 4bit 或同级，禁止微调）
1. listwise prompt：给定查询 + 10 个候选的证据块，输出 JSON：{ranking: [...], confidence_per_candidate: [...], reasoning: 一句话}；
2. 位置偏置校准：候选顺序随机重排跑两遍，分数取平均；
3. 融合与评测同 Phase-2（λ 验证集选、只重排块内、filtered 指标），报告样本内 MRR 及分桶 MRR。

## 任务 P3：Top-50 外恢复测试（新空间）
1. 对 gold∉Top-50 的 500 条查询：LLM 仅根据查询+语言化历史（无候选）自由提名最多 5 个实体；
2. 报告 gold 命中率（recovery rate）与提名候选若插入排名后的 MRR 变化。

## 决策规则（如实执行）
- P2 样本 MRR ≤ 0.4415 且稀疏桶提升 < 0.01 → LLM 验证路线死刑，转入分析向论文或换题讨论；
- P3 recovery rate < 5% → 放弃候选恢复方向；
- 任一方向达标 → 写 docs/task5_pilot/pilot_summary.md，附通过/不通过结论与成本估算（全测试集外推的 GPU 时）。
- 所有中间产物存 results/task5_pilot/，prompt 模板存 configs/。
