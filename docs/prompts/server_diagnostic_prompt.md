# 服务器任务：Phase-2 失败后的诊断包（全部无 LLM、不重训 TiRGN）

## 背景
Phase-2（ICEWS14，3 seeds）结论：最小假设不成立。A=0.4408，F=0.4407，E=0.4412，C=0.4415（+0.0007 约等于噪声）。
关系对齐路径证据（E2/F）无贡献，重复计数（E1/C）有残余微增。详见 docs/task3_experiments/results_summary.md。
现在需要一组诊断实验回答一个问题：**证据重排的失败是"没有空间"还是"证据不对"？**
所有实验基于现有候选缓存 candidates/seed{1,2,3}/ICEWS14_{valid,test}_topk50.pkl 与特征缓存，纯 CPU 完成，禁止重训 TiRGN、禁止任何 LLM。

## 任务 D1：空间诊断（还有没有头部空间）
1. 对配置 A（每个 seed 的 test dump）计算：
   - Recall@K 曲线：K=1/3/5/10/20/50（从缓存直接算）；
   - gold 在 Top-50 内的排名分布直方图（1 / 2-3 / 4-10 / 11-50 / 不在 Top-50）；
   - **Oracle 上限**：若 gold∈Top-50 时将其完美移到第 1 名，filtered MRR 的理论上限是多少；当前 A 与上限的差距（即可重排空间）。
2. 按 subject 历史事件数分桶给出 **A 的绝对指标**（不是差值）：桶 = {0, 1-2, 3-9, 10-99, 100+}，每桶报告 n、MRR、H@1、H@3、Recall@50。需要知道 TiRGN 在稀疏桶到底有多差，才能判断那里有没有空间。

## 任务 D2：特征天花板（是特征没用还是融合没用）
1. 用验证集训练更强的监督重排器（优先 LightGBM，没有就 sklearn HistGradientBoosting），输入 E1-E4 全部特征 + 交互项 + 原始分数归一化值，目标为是否 gold（或 gold 排名分档）；
2. 测试集按与 Phase-2 完全相同的协议评估（只重排 Top-50 内部）；
3. 报告：GBDT 的 test MRR vs 逻辑回归（F）vs A。若 GBDT ≈ A，说明现有特征本身无信息（证据问题）；若 GBDT >> F，说明线性融合是瓶颈（还有救，但理由要重写）。

## 任务 D3：类比证据原型（唯一没测过的证据来源，AnRe 式，无 LLM）
动机：F 在 0-2 桶增益为 0 是因为稀疏实体自身没有历史可挖；但**相似实体的历史**从未被测试过。这是 AnRe 的核心机制，也是唯一可能救稀疏桶的证据来源。
1. 实体相似度：双通道取并集——(a) 实体名 sentence-transformers 语义相似（模型自选小的，CPU 可跑）；(b) 关系画像相似（每个实体参与的关系分布向量，Jaccard 或余弦）；
2. 对历史事件数 ≤ 9 的查询 (s,r,?,t)：取 top-M 相似实体 s'（M∈{5,10,20} 做敏感性），从 s' 的同关系历史 (s',r,o',t'<t) 统计 o' 的重复计数，映射为对 Top-50 内候选的类比分数；
3. 融合与评测同 Phase-2（λ 验证集选、只重排块内），但**只在 0-9 桶查询上启用**，其余查询保持 A 的排名；
4. 报告：0 桶 / 1-2 桶 / 3-9 桶的 MRR 增益（3 seeds），以及全测试集总 MRR（预计几乎不动，正常）。
5. 覆盖率统计：稀疏桶查询中有多少比例能找到至少一个带同关系历史的相似实体——若覆盖率极低（<30%），这条路线也要降级。
