# 任务 5：LLM 语义证据试点（go/no-go）总结

日期：2026-09-26。模型：Qwen3-8B（NF4 4bit，冻结，enable_thinking=False，temperature=0）。
样本：seed1 测试缓存分层 2000 条（S0 0 历史桶 / S1 1-9 桶 / S2 10+ 桶 / S3 gold∉Top-50，各 500）。
中间产物：`results/task5_pilot/`（p1_samples.jsonl、p2_llm_scores.jsonl、p2_eval.json、p3_nominations.jsonl、p3_summary.json）。
Prompt 模板：`configs/p2_listwise_prompt.md`、`configs/p3_recovery_prompt.md`。

## 最终结论：不通过（两个方向均未达标）

### P2 冻结 LLM 候选验证（listwise，两遍 shuffle 校准，1500 查询，解析成功率 99.2%）

评测协议与 Phase-2 一致（λ 在样本校准半区选取=0.5，只重排 Top-10 展示前缀，eval 半区 750 条）：

| 方法 | 全部 (n=750) | S0 0 桶 (n=250) | S1 1-9 桶 (n=250) | S2 10+ 桶 (n=250) | 稀疏合计 (n=500) |
|---|---|---|---|---|---|
| A（TiRGN 原序） | 0.5303 | 0.4829 | 0.5392 | 0.5687 | 0.5110 |
| 融合（λ=0.5） | 0.5280 | 0.4794 | 0.5394 | 0.5651 | 0.5094 |
| 纯 LLM 排序 | 0.2818 | 0.2628 | 0.2904 | 0.2922 | 0.2766 |

- 融合相对 A：**-0.0023（整体）、-0.0016（稀疏桶）**——LLM 置信度是负贡献；
- 纯 LLM 排序 MRR 仅 0.28，远低于 TiRGN 分数——冻结 8B 模型对 ICEWS 行为体证据块的判断远不如模型分数；
- 校准半区 λ 曲线：0.1→0.5090，0.5→0.5100，≥5 时急剧劣化（10.0→0.4276），说明 LLM 信号稍一放大就有害。

决策规则执行：稀疏桶提升 -0.0016 < +0.01（FAIL）；样本融合 MRR 0.5280 虽高于 0.4415 的字面阈值，
但该阈值是相对全测试集统计天花板设的，而样本内统计基线本身即 0.5303——按规则意图
（LLM 须超过统计基线/天花板）判定 **P2 不通过**。

### P3 Top-50 外恢复测试（500 查询，自由提名 ≤5 实体，解析成功率 100%）

| 指标 | 值 |
|---|---|
| recovery rate | **1.4%（7/500）**，阈值 5% → FAIL |
| S3 样本 MRR（原排名） | 0.0058 |
| 假设命中即按提名位次插入 | 0.0156（+0.0098，仅该层；折合全测试集约 +0.002 上限） |

→ 按决策规则**放弃候选恢复方向**。

## 成本估算（全测试集外推）

- P2 形态：1500 查询 × 2 遍 ≈ 11.5 GPU 时（4090，4bit）→ 全测试集 26444 查询 ≈ **200 GPU 时（约 8.5 天/卡）**，
  且收益为负；
- P3 形态：500 查询 ≈ 20 min → 全量低成本，但 1.4% 命中率无意义。

## 分析与建议（如实）

1. 冻结 8B LLM 在"读懂证据块并排序"任务上不敌 TiRGN 分数，与诊断包结论一致：
   计数统计之外的语义信号在 ICEWS14 实体粒度上要么太弱、要么被模型分数覆盖；
2. 稀疏桶是 LLM 唯一理论上有价值的场景（无计数可统计），但实测 -0.0016，假设被证伪；
3. 恢复方向的瓶颈不是召回能力而是实体空间对齐：LLM 提名的实体多半不在 ICEWS14 词表内
   或粒度不匹配（7 次命中全部依赖名称精确/归一化匹配）；
4. 按 prompt 决策规则，**LLM 证据验证路线终止**，建议转入分析向论文（系统性的
   "统计证据触顶 + LLM 语义证据负收益" 负结果在 ICEWS14/ TiRGN 上有完整证据链：
   Phase-2 → D1-D3 → P2/P3），或换题讨论。
