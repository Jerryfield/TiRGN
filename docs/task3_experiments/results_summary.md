# 任务 3：Phase-2 对比实验汇总（ICEWS14，3 seeds，全程无 LLM）

日期：2026-09-23。数据：ICEWS14。评测：filtered ranking，ground-truth history，subject+object 双向查询。

## 核心结论（如实报告）

**本研究最小假设在当前设置下不成立**：F（TiRGN + RCEV，关系对齐路径 + 对比特征）相对 A（纯 TiRGN）
没有提升（0.4407 vs 0.4408），且不优于 E（通用候选条件证据，0.4412）。所有配置相对基线的最大提升
仅 +0.0007 MRR（C，全历史重复计数），约 0.07 个点，远小于 seed 间差异可感知的量级边界（std 0.0005-0.0009）。
证据信号中唯一稳定微涨的是「重复计数类」特征（C / abl_E1），关系对齐路径证据（E2 / F）无贡献。

## 实验设置

- 3 个 seed（1/2/3）各自完整重训 TiRGN 500 epoch（超参与 README 基线一致，见 `configs/task3_icews14.md`），
  新增 `--seed` 注入 random/numpy/torch/cuda，不改模型逻辑；
- 每个 seed 的 best checkpoint 各自 dump 验证集+测试集 Top-50 候选缓存，证据实验全部离线进行；
- 证据权重：逻辑回归只在验证集拟合；λ 从固定网格 {0.01..1.0} 在验证集 MRR 上选取后一次性用于测试集；
- 融合 z' = z + λ·ρ·e，只重排 Top-K 内部，块外实体原位，filtered 指标保持有效；
- 运行脚本：`scripts/train_seed.sh`、`scripts/dump_seed.sh`、`src/evidence/run_experiments.py`。

按 subject 历史事件数分桶的 MRR 增益（F−A，3 seeds 趋势一致）：

| 桶 | n（约） | seed1 | seed2 | seed3 |
|---|---|---|---|---|
| 0-2 | 1500 | +0.0000 | -0.0001 | +0.0000 |
| 3-9 | 1700 | +0.0003 | +0.0000 | +0.0001 |
| 10+ | 18000 | -0.0002 | -0.0002 | -0.0002 |

解读：有益翻转略多于有害翻转（净 +0.2~0.3pp），但 gold∈Top-K 的 MRR 三个 seed 全部微降——
有害翻转多发生在高位（把 gold 从第 1-2 名挤下去，代价大），有益翻转多发生在低位（提升有限）。
低历史桶（0-2）F 完全无增益（无证据可挖），高历史桶（10+，占 86% 查询）稳定微负。

## 分析与讨论（假设不成立的原因推断）

1. **TiRGN 已经吃掉了大部分历史信号**：模型本身含 history vocabulary 复制机制（history_rate=0.3），
   重复类证据（E1/C）只剩 +0.0004~0.0007 的残余增益，说明 copy 信号与模型冗余度高；
2. **E2 路径证据太稀疏/太噪**：规则挖掘对 15 个 hub 实体做了连接数截断（见任务 2 文档的已知近似），
   且置信度用静态近似估计；高历史桶（10+）增益为负，说明路径证据在历史丰富时反而引入噪声；
3. **融合方式受限**：z' = z + λ·ρ·e 的线性融合 + Top-K 内部重排，证据能改变的只有块内顺序，
   而 TiRGN Top-1 已经较强的查询（H@1≈0.34）块内重排空间有限；
4. **对 LLM 路线的含义**：如果候选条件证据的统计形态（E2/F）都无法超过 query-only 重复基线（C），
   那么"为候选构造关系对齐证据链让 LLM 验证"的价值需要重新论证——LLM 可能的剩余价值在于
   (a) 非线性/语义层面的证据理解（统计特征无法捕捉），(b) 低历史桶的泛化（本实验 F 在 0-2 桶增益为 0），
   (c) 更大 K 或块外候选的恢复（本实验硬性限制 Top-K 内部）。建议下一步先在低历史桶和
   Top-K 外恢复两个场景单独评估，再决定是否继续 LLM 路线。
